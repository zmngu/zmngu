# To DO List App

A simple web-based to-do list app that was built using HTML, CSS and Javascript. 
The to-do list has a local memory in order to save all the created tasks until they are deleted. 
The to-do list track the number of tasks and how many of the tasks have been completed with a progress bar.

### To Run the App:
Open the folder in your IDE, 
run the HTML file and your browser should open.
